## Prediction as a SQL primitive

`forecast()`, `detect_anomalies()`, and `predict()` become functions you call
over an ordinary `SELECT`. The core is one small C99 file with no dependencies,
so it runs in your app, on a phone, in the browser, or in the per-database state
an AI agent keeps. Every result carries a **replayable receipt**, so an agent
can cite the number and an auditor can reproduce it byte-for-byte.

```sql
-- forecast a metric 24 steps ahead. rows in, rows out.
SELECT step, forecast, lower_bound, upper_bound
FROM forecast('SELECT ts, value FROM readings', 24);
```
